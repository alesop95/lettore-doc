Nell'output diagnostico `skipped_sensitive` risulta pero' vuoto perche' la lista si popola solo nel loop `for p in all_files` a valle del pre-detect: quando il pre-detect abortisce sotto soglia, i file non arrivano mai fino al log. Workaround adottato in sessione: cartella parallela `_intermediate/src/Cybersec-governance-baseline-sanitized/` con file rinominati (`password` -> `autenticazione`) e convertiti `.docx` -> `.md`. Correzione applicata in sessione via edit chirurgico del `taxonomy_diff.sanitized.json` prima di export (spostamento capability slug + domain sui 18 fit interessati), non alla radice. Da valutare: rimuovere `certification`/`certifications` dalle keyword di Quality Certification (poco distintive) o alzarne il weight-down, e aggiungere `data breach`, `gdpr`, `dpo`, `garante`, `wp250`, `art. 33`, `art. 34` alle keyword di Cybersecurity & IT Governance per rendere il match diretto.
